The Anatomic Locations Index (ALI) is part of the [Open Imaging Data Model (OIDM)](https://www.openimagingdata.org), an open, vendor-neutral model for representing radiology findings as coded data. OIDM has four shared vocabularies: finding models, common data elements, anatomic locations, and exam types. The ALI is its vocabulary of anatomic locations.

Tarik Alkasab founded the OIDM Initiative, the multi-institutional working group that develops OIDM, and leads it with Michael Hood. The group posts articles on the [OIDM website](https://www.openimagingdata.org) and publishes its code and data models in the [openimagingdata](https://github.com/openimagingdata) GitHub organization. Tarik Alkasab maintains the [OIDM knowledge base](https://github.com/openimagingdata/oidm-knowledge), the reference for OIDM's vocabularies and data structures.
